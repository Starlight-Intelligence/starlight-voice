The anatomy

One utterance, seven stages, under a second.

The voice loop is a single in-process pipeline. Each frame flows left to right; a router stamps every turn with a tier so the slow, expensive stages only run when the request actually needs them.

  1. Capturepush-to-talk
  2. STTGroq Whisper
  3. Routertier stamp
  4. Memoryrecall if needed
  5. LLMprovider-pinned
  6. TTSElevenLabs Flash
  7. Audiofirst sound

A control phrase short-circuits before the LLM. A simple answer skips memory recall. The expensive path runs only when the tier earns it — that's where the sub-second budget comes from.

The fleet

It doesn't just answer. It dispatches.

When a turn is real work — "refactor the auth module in FrankX" — the operator classifies it, picks the right agent for the right repository from your own agent-sessions.json, and spawns it in the correct tree. Nothing mutating runs until it clears the gate.

A

Read-only

Provably read-only, no mutation marker. Runs immediately.

"show me the diff"
B

Mutating · ack

The default. Read back the resolved command, wait for your okay.

"refactor the parser"
C

Substrate

Touches protocol or sovereignty. Escalates to the board.

"change the schema"
D

Always-ask

Rotate a key, force-push, drop a table. Hard stop — never auto-runs.

"reset --hard"

The gate is default-deny: a request earns Tier A only on a positive read-only signal with no mutation anywhere. Everything else waits for you.

It remembers your world

Grounded in your own context — degrade-first.

Non-trivial turns recall from the Starlight memory gateway over localhost: hybrid retrieval that fuses keyword and semantic search, framed as untrusted context the model reasons over. If the gateway is down, the operator keeps talking — recall degrades, the loop never breaks.

  • RRF hybrid retrieval — keyword + semantic, ranked together
  • Bearer-token auth on a 127.0.0.1-bound gateway
  • Tier-conditioned: simple turns skip the round-trip
  • Fails open to conversation, never to a stall
